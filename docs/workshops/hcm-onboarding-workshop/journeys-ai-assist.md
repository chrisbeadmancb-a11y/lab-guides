# Draft a first-week onboarding checklist

The same employee needs three tasks they can complete during their first week. Use Journeys AI Assist to draft the checklist and review it before saving anything.

## Open Create Journey

1. Sign in to Fusion using the instructions in <a href="../../labs/lab-environments/" target="_blank" rel="noopener">Lab Environments</a>.
2. From the home page, choose **My Client Groups**, then **Journeys**, then **Explore**.
3. Select **Create Journey** and choose **AI Assist**.
4. Set **Category** to **On Boarding**.

![Create Journey in Journeys Explore, with AI Assist chosen and Category set to On Boarding.](https://sharonewest.github.io/hcm-onboarding-workshop/journeys-ai-assist-full-page.jpg)

## Generate task suggestions

Use **Copy** to paste this brief into **What type of template do you want to create?**

```
<copy>Draft three first-week checklist tasks for a remote hire starting Monday. Address each short instruction to the new starter, who owns all three tasks.

Cover these actions: use the invitation to set up the work account, attend the team orientation, and check work contact details in the HR profile. For the account task, tell the starter to contact their hiring manager if the invitation has not arrived. Base the checklist only on this brief.</copy>
```

Select the **AI Assist** button below the field. When **Task suggestions** appears, compare the results with [the shared onboarding policy](?lab=onboarding-policy).

## Review three tasks and cancel

Choose one suggestion for each topic. Check that the employee can carry out each action.

| Topic | What the employee should be able to do |
| --- | --- |
| Work account | Use the invitation to set up the account. Tell the hiring manager if the invitation is missing. |
| Team orientation | Find the session details and attend the orientation. |
| HR profile | Open the profile and review the employee’s work contact details. |

Select **Cancel** to return to **Explore** and leave the draft unsaved.

## Help with Journeys

Ask the workshop host to check your access if **Explore**, **Create Journey**, **AI Assist** or the **On Boarding** category is missing.
