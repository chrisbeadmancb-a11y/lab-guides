# Answer an onboarding policy question

The hiring manager wants to know who orders the laptop, when IT sends the account invitation and who should follow up if it hasn’t arrived.

## Open the policy advisor

1. Sign in to Fusion using the instructions in <a href="../../labs/lab-environments/" target="_blank" rel="noopener">Lab Environments</a>.
2. Open **Navigator**, choose **My Team**, then **Team Activity Center**.
3. Find the **Employment Lifecycle Policy Advisor** card and select **Ask Oracle**.

![The Employment Lifecycle Policy Advisor card and its Ask Oracle button in Team Activity Center.](https://sharonewest.github.io/hcm-onboarding-workshop/policy-advisor-full-page.jpg)

## Ask about the laptop and account invitation

Select **Copy**, paste the prompt into **How can I help you?** and press **Enter**.

```
<copy>A remote hire starts on Monday. Answer their manager using only sections 2 and 3 of the Remote new starter onboarding policy. Use the two headings below.

Section 2 — Equipment
Write one bullet. Identify who requests the laptop and the minimum lead time.

Section 3 — Account access
Use this sentence as the first bullet: “The IT service desk sends the account setup invitation before the new starter’s first day.”
In a second bullet, give the full deadline for a missing invitation and explain how the hiring manager follows up. Include “noon in the new starter’s local time” in that deadline.

State the deadline and follow-up only once. Keep the policy’s relative deadlines exactly as written, omit dates and weekdays, and finish after the second account-access bullet.</copy>
```

Compare the answer with [sections 2 and 3 of the shared policy](?lab=onboarding-policy). Check who opens the equipment request, when the invitation is due and which ticket the manager uses if it is missing.

## Help with the advisor

If the card or **Ask Oracle** is missing, ask the workshop host to check your access. If the response cites another policy or leaves out a deadline, show the host the response you received.
