# AI for onboarding in Oracle Fusion HCM

A remote employee joins your team on Monday. Their manager needs to know when to request a laptop and what to do if the employee’s account invitation is late. You’ll use the policy advisor to answer those questions, then switch to Journeys to draft the employee’s first-week tasks.

## Before you start

Open the Fusion test environment using the <a href="../../labs/lab-environments/" target="_blank" rel="noopener">link and sign-in instructions</a>. Keep this guide open in a separate tab.

1. [Lab 1 · Ask the policy advisor](?lab=policy-advisor) — check the manager’s responsibilities and deadlines against the onboarding policy.
2. [Lab 2 · Draft a first-week checklist](?lab=journeys-ai-assist) — generate three tasks for the employee and review them before closing the draft.

Both exercises use the [Remote new starter onboarding policy](?lab=onboarding-policy).
